# Voltrio

Téléchargements de Voltrio, le client mail de bureau centré sur la confidentialité.

**Installer** : ouvrez la dernière version dans [Releases](../../releases/latest), téléchargez le `.dmg`, puis glissez Voltrio dans Applications.

Les mises à jour sont ensuite proposées dans l’application. Chacune est signée, et sa signature est vérifiée avant installation.
